# Skill 经验库索引（deepseek-web-search-plugin 主项目）

> 本文件夹是主项目的**经验与技能库**，与子项目 `search-api-service/skill/` 结为姊妹库、结构同构。
> 分三库：**主项目经验（原文）／子项目经验（原文，一字不动）／双方融合经验（提纯合并）**。
> 主项目 AI 与维护者进入本文件夹后，按下面的顺序读。

| 顺序 | 位置 | 内容 | 什么时候读 |
|---|---|---|---|

| 3 | [03-双方融合经验/](03-双方融合经验/) | 两边经验去重、提纯、合并后的"当前最优实践"——**唯一可修订的库** | 日常开发对照检查 |

## 迭代规则

1. **原文尊重**：01 / 02 是原始存档，**只增不改不删**；发现原文过时 → 在新条目中标注弃用并说明，不动原文（保留演化轨迹）。
2. **新经验先归位**：主项目踩的坑先记 01，子服务的记 02（去子服务那边写），定期蒸馏进 03。
3. **bug 修复走台账**：主项目走《代码问题清单_当前版》销账制，子服务走 `search-api-service/docs/BUGS.md`；只有方法论层面的收获才进本库。
4. **姊妹库互通**：子服务经验库（`../search-api-service/skill/README.md`）同步迭代；两边索引互链，谁的原文谁维护。
5. **给 AI 的约定**：修完先自证三连（编译/语法 → 数据落盘 → 端到端）；汇报区分"已验证事实"与"推测"；"检查/审核"不等于"修改"，用户未明确说改就不改。
